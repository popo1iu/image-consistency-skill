# 图片一致性

把一致性落实为可对照的保留项、允许变化项和验收依据。覆盖主体身份、文字内容、文字排版、元素清单、空间关系、视觉风格及输出规格。不能用“整体风格相似”替代文字、数量或位置的正确性，也不承诺生成编辑能做到像素不变。

## 确定任务与基准

- 查看可用图片和可编辑源文件，区分编辑底图、人物身份、产品结构、文字与排版、布局、风格以及待插入素材等参考作用。不要把风格参考中的文字、人物或道具误带入结果。
- 用户指定的基准优先；没有指定时，使用最早满足要求且清晰的图，简短说明后继续。使用最近已接受的版本保留后续编辑，同时保留原始基准用来检查累计漂移。
- 用户要求改现有图片时按编辑处理，不从文字描述重建整张图片。仅以图片作参考生成新场景时，明确哪些维度需要继承。
- 新建系列且没有参考时，先完成首张，将其作为临时基准，再继续已授权的系列。不要额外制作未请求的三视图或素材包，也不增加首张审批流程。
- 图片缺失且任务依赖它时索取原图；不能冒充看过参考。冲突优先遵循用户最新明确指令，仅在无法判断且会实质影响结果时提问。

## 把要求变成一致性卡

在工作上下文维护简短记录；有系列或跨会话复用需要时，按当前环境输出规则保存记录和图片引用。不要要求用户逐项填写可由图片直接判断的信息，也不要声称跨会话自动记住图片。

每项标记为“保留”“本次修改”或“允许随情境变化”，注明来自用户、源文件、实测还是目测。用户最新明确修改覆盖对应旧锁定项，不解除其他保留项。未指定的属性继承基准；无基准时作合理设计选择并用于后续系列。

| 维度 | 按任务记录的属性 |
| --- | --- |
| 基准与规格 | 原图或源文件位置、版本、画布宽高、比例、方向、裁切、透明背景要求 |
| 主体身份与结构 | 可见五官、发际线、体型、发型、服装、配件；产品轮廓、比例、零件、接口、数量、材质 |
| 文字内容 | 每个文字块的准确文本、显式换行、标点、大小写、数字、单位、语言及对应元素 ID |
| 字体与排版 | 字体家族与实际字形、字号、字重、字宽、斜体、字距、词距、行距、段距、对齐、文字框、文字方向 |
| 元素与布局 | 每个元素的 ID、数量、位置、大小、比例、旋转、裁切、锚点、前后顺序、遮挡、组关系、对齐、间距、留白 |
| 视觉外观 | 色彩、材质、纹理、线条、渲染方式、描边、圆角、透明度、阴影及光照关系 |
| 本次变化与验收 | 修改目标、连带变化范围、关键保留项及其检查方式 |

只记录有依据的信息。不能从位图确定精确字体名称、字号或层级树；目测的几何量应标为近似。颜色代码仅在用户提供或实际取样时作为精确值。未能辨读的关键文字不能猜写，应向用户索取文案或清晰原图；其他独立部分可继续。

## 文字内容与排版锁定

- 按独立文字块登记，正文、标题、按钮、标签、脚注和产品表面文字分别对应，避免文案串位。准确保留字符、标点、空格、大小写、数字、单位及行顺序；不擅自润色、翻译、缩写或纠错。
- 区分文案中的显式换行和文字框宽度造成的自动折行。未要求改排版时保持可见行数、断行位置、对齐基线及文字框边界。
- 锁定字体家族、字重、字号、字距、词距、行高、段距、对齐、颜色、描边、阴影及旋转。源文件可用时从源属性读取；仅有位图时记录可见字形特征和相对尺寸，不将相似字体宣称为原字体。
- 不把“粗体”自动解释为某个确定数值；中文字体的标点、数字和拉丁字形也属于字体一致性。原字体缺失时说明差异，不静默替换后声称完全一致。
- 用户只改背景或主体时，将文字整体视为保留区，避免要求生成工具重绘不需要变化的文字。能在授权工具中保留原文字图层时优先保留。
- 替换文案时，默认继承原排版样式和文字框。新文案装不下时先尝试不改变其他锁定项的适配；不得悄悄删字、改义、缩小字号或改变字距。没有可行方案且取舍影响需求时，简短询问允许改变哪项。
- Logo、商标、二维码、条码、图标内文字及包装细字作为独立保留元素。要求准确复用时保留可靠原素材；不以看起来相似的重绘替代。没有实际扫描验证不得声称二维码或条码可用。

## 元素与空间关系锁定

- 对任务相关的可见元素建立清单与稳定 ID，如标题 T1、产品 P1、图标 I1。记录数量与归属；检查新增、遗漏、重复、替换和错位。群体、重复纹样或复杂背景按影响任务的适当粒度记录，不机械枚举每个像素。
- 位置使用统一坐标：注明画布尺寸、左上角为原点，以及像素值或归一化坐标；边界框用 x、y、宽、高，避免混用中心点和左上角。不捏造测量值或自行设定未经依据的验收容差。
- 大小同时关注宽高、长宽比、主体相对画布占比和组内比例；不得为适配版式无意拉伸人物、Logo 或产品。锁定旋转、裁切、可见范围及与边缘的距离。
- 将“层级”拆为前后遮挡顺序和视觉主次：前者检查谁覆盖谁，后者检查标题、主视觉、正文和辅助信息的尺寸、对比度与阅读顺序。位图中只推断可见遮挡，不宣称恢复了源图层结构。
- 记录成组关系、共用边线、水平或垂直对齐、中心轴、基线、等距关系、元素间距、组内间距和页边留白。优先保留这些关系，不能只固定每个元素的孤立位置。
- 同尺寸局部编辑时，未涉及元素的几何位置和排版保持基准。改机位或姿态时，允许透视、遮挡和对应投影合理变化，不把主体空间变化与页面布局变化混为一谈。
- 用户要求改变画幅或系列适配时，使用锚点、比例和相对间距调整；不要直接拉伸或把所有旧坐标照搬到新画布。区分系列共享的字体、网格、色板、边距和组件样式，以及每张变化的场景或文案；不强迫不同场景拥有完全相同构图。

## 检查可用插件与辅助定位

当任务需要文字、图层、坐标或布局精度时，先检查当前环境已暴露的工具、已安装插件及其连接状态，寻找能直接读取目标的能力。普通改图已有足够工具时直接执行，不为每张图强制搜索插件。插件发现与连接状态按 plugin-management 技能执行；实际使用某个专业插件时，先读取其适用技能并遵守访问规则。

### 按能力选择，不按名称猜测

- 优先使用能直接读取目标源文件的现有工具或已连接插件，例如设计文件中的节点、文字样式、边界框、变换矩阵、分组、自动布局及层级。Figma、Canva 或其他设计工具只有在实际开放相应读取能力、且目标文件可访问时才可使用；不能因插件名字相关就认定它能读取图层或本地图片。
- 源文件读取不到时，可使用实际可用的 OCR、图像测量、取色或叠图工具辅助定位。OCR 的文本与框位置、字体识别候选、取色结果应分别记录，不互相替代。低置信度或无法辨读的内容保持“待核实”。
- 只有截图或浏览器画面时，用受支持的浏览器或界面工具查看和定位；先确认它可访问当前目标。截图坐标只能作为画面定位依据，不能直接当作原图坐标、字体属性或图层数据。环境禁止的桌面控制不能由技能启用。
- 区分本地技能、插件安装、外部账号连接和当前文件访问权。技能文件存在不等于插件已连接，插件已连接也不等于能访问本地文件。使用已暴露的发现与状态工具核实，不扫描整个磁盘、账号或无关文件。
- 只有缺少的能力确实会改善当前任务时，才搜索相关插件及依赖。发现未安装或未连接的插件后可提出最少必要建议，继续不依赖它的工作；不得自行安装软件、连接账号、修改权限、上传本地素材或同步到外部工作区。外部传输或写入需在用户授权范围内，不能把“辅助定位”解释为额外授权。
- 用户指定的插件或本地应用优先，但仍需核实实际能力。插件不可用时降级为现有工具和目测，并标明精度限制，不宣称完成了插件定位。

### 将定位结果接入一致性卡

为相关元素建立“参考元素 ID → 源节点 ID／图层名称／文字块 → 定位依据”的映射，附带文件版本和画布或页面范围。相同名字的节点不能只按名字匹配；结合父组、内容、位置及角色确认目标。没有源节点时使用本任务内稳定 ID，不伪造节点编号。

位置与尺寸注明坐标系、单位和数据来源。源文件可能使用 pt、逻辑单位或带缩放的局部坐标；不能直接标成输出像素。对截图标注截图尺寸、视口缩放、原图缩放、裁切偏移或面板偏移中实际已知的部分，转换到画布坐标后再比较。包含旋转或嵌套变换时使用正确变换；转换依据不足则只作近似视觉定位。

区分数据可信度：直接读取的源属性、实际测量结果、工具候选和目测推断分别标注。源文件的字体名称不代表字体文件已安装，文本节点边界框也不等于可见字形边界。不要对位图元素伪造精确字号、真实层级或坐标小数精度。

辅助定位默认先只读检查。在已授权编辑中，按确认过的节点或区域做局部修改，保留无关节点；不因插件可以编辑就扩大改动。检查后的目标文件或页面发生变化时重新定位，不能沿用过期坐标。修改后读取实际属性或重新查看导出图，对照一致性卡检查；插件返回成功只证明操作已执行，不证明文字、布局或成图正确。

## 选择执行方式

- 实际生图和编辑默认使用内置图像工具，遵守当前工具说明及 imagegen 的相关规则。用户仅要提示词时只交付提示词。创建或更新本技能不意味着授权额外生成图片。
- 编辑本地图片前先查看。工具支持本地参考路径时使用实际路径；否则使用支持的对话图片引用。确保全部关键输入可传入，无法传入时索取图片。若工具具有 referenced_image_paths 和 num_last_images_to_include，遵守当前说明二选一；无参考的新图不传参考参数。
- 用参考图和具体保留项控制一致性，不编造 seed、参考权重、蒙版或身份锁定参数。固定 seed 本身也不能保证身份与布局一致。
- 用户要求精确文字、布局或区域外像素不变时，优先在授权且可用的源文件、图层或合成工具中保留不变元素；图像工具用于需要生成的部分。遵守环境对图像编辑工具的要求，不擅自用脚本绕过必须使用的工具。
- 只有生成工具可用时，明确其不能保证精确字形、坐标或像素，不把提示词写了要求等同于实现了要求。继续完成可行部分，交付时注明实际偏差。工具不可用时说明阻碍，不静默切换付费 API 或外部服务。

## 每次调用提供可执行的约束

按实际任务取用下列结构，不给工具塞入无关清单：

```text
任务：本次生成或编辑的具体目标。
输入角色：各图的实际序号及用途，包括编辑底图和原始基准。
允许变化：本次改变的对象、属性和必要连带影响。
主体保留：身份、结构、数量、比例及关键识别特征。
文字保留：逐块提供准确文本、换行、位置和关键字体排版属性。
元素布局：相关元素的边界、锚点、比例、组关系、前后顺序、对齐和间距。
风格与规格：继承的外观、画幅及透明要求。
禁止漂移：本次最关键的具体错误，例如标题重排、图标缺失、Logo 变形或产品零件变化。
```

每次重述关键约束并传入真实参考，不只说“和上一张一样”。例如“只改背景”应同时保留标题文案、断行、字体外观、字号、文字框、Logo 与产品位置、大小及它们的间距。只有用户允许的属性解除锁定；避免换光线同时要求所有阴影像素原封不动等矛盾条件。

## 检查、迭代与交付

- 查看输出后分别检查：用户修改是否实现；主体身份结构；逐块文字内容；字体与断行；元素数量与完整性；位置、大小、比例、对齐、间距与层级；风格外观；画布与裁切。不能只凭缩略图整体观感判定通过，文字和小图标需查看到可辨识程度。
- OCR 如可用仅作辅助，人工对照文字和原图；OCR 不能验证字体、字号或布局。需要精确性且工具允许时可做叠图、属性或像素对比，实际执行后才能报告结果。视觉近似不等于精确数值相等。
- 使用“符合／有偏差／无法核实”，不编造相似度百分比或检测结果。不能查看输出时明确尚未完成视觉核验；无法读取源属性时不声称精确字体和字号已验证。
- 发现关键漂移时进行针对性修正，重新带上可靠基准并锁住已正确部分。修正应对应具体错误，避免每次重新设计整图。检查后再扩展系列，避免批量复制错误。
- 持续有改善且存在明确修正方案时继续完成已授权工作；同一问题连续两次修正仍无改善时停止盲目重试，保留最佳版本并说明问题和可行替代方案。不得将已知关键错误标为通过。
- 每张系列图仍对照原始基准和共享规则；不能把上一张的错字或偏移当成新标准。用户改变某一设定时仅更新对应字段，记录新版本。
- 保留原文件并保存版本，只有用户要求替换才覆盖。优先展示图片，简短说明已完成的变化和仍存在的偏差，提供所需文件链接。需要复用时提供一致性卡及可读取的参考位置；不强制向用户展示完整内部清单。
