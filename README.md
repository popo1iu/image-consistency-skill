# Image Consistency Skill · 图片一致性

让图片修改和系列创作有一份可检查的保留清单：人物与产品、准确文字、字体排版、画面元素和布局关系，都有明确依据。

适用于局部改图、海报与包装修改、产品多场景图、连续插画，以及需要沿用同一套视觉规则的系列图片。

## 解决什么问题

- 换背景时，人物、产品、标题和 Logo 跟着变了。
- 文案没要求改，却出现错字、重排或字号变化。
- 图标和配件遗漏、重复，元素位置、大小或间距发生偏移。
- 连续修改后，结果越来越偏离最初参考图。
- 只有一句“保持一致”，没有具体检查标准。

## 核心能力

| 范围 | 保留与检查的内容 |
| --- | --- |
| 主体 | 人物身份、发型、服装、配件；产品结构、比例、零件与材质 |
| 文字 | 准确文案、标点、大小写、数字、单位、换行和文字块对应关系 |
| 排版 | 字体、字号、字重、字距、行距、对齐、文字框及文字效果 |
| 元素 | 数量、位置、大小、比例、旋转、裁切、分组、遮挡与视觉主次 |
| 布局 | 锚点、基线、对齐、留白、组内间距与元素间距 |
| 风格 | 色彩、纹理、线条、光照和渲染方式 |
| 辅助定位 | 检查可用插件，按实际能力读取源节点、图层或文字属性；必要时用 OCR 和测量辅助 |
| 复核 | 对照原始基准逐项检查，区分符合、有偏差和无法核实 |

## 工作方式

1. 查看参考图，明确每张图片的用途。
2. 建立一致性卡，区分保留项、本次修改项和可随情境变化的内容。
3. 根据当前可用工具选择图像编辑、源文件编辑或辅助定位方式。
4. 将具体约束与真实参考一起用于每次修改。
5. 查看结果并检查偏差，针对问题修正，保留版本与原始基准。

插件辅助定位按实际能力启用，不假设安装插件就能读取所有文件，也不自动安装插件或连接账号。

## 安装

将本仓库中的 `image-consistency` 文件夹复制到个人 Codex 技能目录：`$CODEX_HOME/skills`；未设置 `CODEX_HOME` 时使用 `~/.codex/skills`。

文件结构：

```text
image-consistency/
├── SKILL.md
└── agents/
    └── openai.yaml
```

`SKILL.md` 是技能入口，保留此文件名。文件夹名与技能名均为 `image-consistency`。

## 工具与精度

这是给 Codex 使用的工作流程技能，不包含独立图像模型、OCR 引擎或字体识别程序。实际生成和编辑需要当前环境提供相应工具；插件、OCR 和源文件读取属于按需使用的辅助能力。

提示词和参考图可以减少漂移，不能保证像素完全不变。精确文字、Logo 和布局优先保留可靠源素材或可编辑图层；只有位图时，不能把目测字体、字号或位置当作精确读取结果。

本技能不包含示例生成图片，也未通过实际图片端到端测试。当前验证范围为文件结构与工作流程规则检查。
